# Personal Expense Tracker

A command-line expense tracker built with Python.

## Features
- Add expenses with a description and amount
- View all recorded expenses
- Calculate total spending
- Delete expenses
- Save expenses to a JSON file so they persist between sessions
- Handle invalid menu choices and invalid expense amounts

## Technologies Used
- Python
- JSON
- `os` module

## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run

## What I Learned
This project helped me practise Python loops, conditional statements, lists, functions such as `enumerate()`, exception handling, file handling, and working with JSON data.
